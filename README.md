# CUDA Optimization Project – Accelerator Programming Summer School (June 2024)

This repository contains the CUDA programming project completed during the Accelerator Programming Summer School at Seoul National University in June 2024.

Project Summary
	•	Implemented baseline and optimized CUDA kernels for parallel computation tasks
	•	Focused on GPU performance tuning and CUDA kernel optimization
	•	Explored techniques such as shared memory usage, loop unrolling, and memory access optimization
	•	Compared performance across different implementations to analyze optimization impact
	•	Worked in a 2-person team to design, implement, and evaluate CUDA programs

🔧 Tools used: CUDA, NVIDIA GPU, C++
